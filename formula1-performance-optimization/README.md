# Formula 1 Performance Optimization

## Overview

Analytical project focused on optimizing Formula 1 vehicle performance through mathematical modelling of aerodynamic forces, friction constraints and tyre degradation.

## Objectives

- Minimize lap time.
- Model aerodynamic drag and downforce.
- Analyze tyre degradation effects.
- Determine optimal vehicle configuration.

## Methodology

- Mathematical modelling
- Constrained optimization
- Lagrange multipliers
- Numerical analysis

## Tools Used

- Python
- Octave
- Mathematical Optimization
- Data Analysis

## Skills Developed

- Operations Research
- Mathematical Modelling
- Optimization Techniques
- Data Analysis
- Problem Solving

## Results

The project identified the optimal balance between aerodynamic load and tyre degradation to improve overall race performance.
