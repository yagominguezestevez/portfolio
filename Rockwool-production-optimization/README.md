# ROCKWOOL Production Optimization Analysis

## Overview

Operations improvement project focused on the analysis and optimization of ROCKWOOL's stone wool manufacturing process. The project identifies production bottlenecks, proposes Lean Manufacturing initiatives and evaluates performance improvements through simulation techniques. 

## Key Activities

- Production process mapping
- Bottleneck identification
- Plant layout analysis
- Lean Manufacturing proposals (SMED and waste reduction)
- Industry 4.0 technology assessment
- KPI development
- Monte Carlo simulation modelling 

## Results

- +13.6% throughput increase
- -23.8% process variability reduction
- Predictive maintenance roadmap
- Industry 4.0 implementation plan
