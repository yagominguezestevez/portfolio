# Environmental Data Analytics
## Overview
 
Comparative analysis of NO₂ pollution levels in Madrid and Barcelona using official open environmental datasets from 2020 to 2023. The project combines data quality assessment, exploratory analysis, historical trend evaluation and predictive modelling.
 
## Key Activities
- Data collection from official environmental databases
- Data cleaning and quality assessment
- Missing values and outlier analysis
- Descriptive statistical analysis
- Time-series comparison between cities
- Linear regression modelling
- Interactive Excel dashboard development 
 
## Key Findings
- Madrid showed higher average NO₂ levels than Barcelona.
- Both cities displayed strong seasonal pollution patterns.
- Significant decreases occurred during COVID-19 lockdown periods.
- Long-term trends remained weak, with seasonality driving most variability.
