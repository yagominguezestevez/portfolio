# Lean Six Sigma (DMAIC) Quality Improvement Project

## Overview

Quality management project developed for Turyelectro Galicia S.L. using the Lean Six Sigma DMAIC methodology.

## Objectives

- Identify process inefficiencies
- Analyze root causes
- Propose corrective actions
- Improve quality performance

## Tools

- Lean Six Sigma
- DMAIC
- Excel
- Pareto Analysis
- Ishikawa Diagram

## Skills Developed

- Quality Management
- Process Improvement
- Data Analysis
- Problem Solving
